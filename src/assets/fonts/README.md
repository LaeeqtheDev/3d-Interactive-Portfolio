# Fonts

Self-hosted, Latin subset only, so the site makes no third-party font request.

| File | Family | Licence |
|---|---|---|
| `bricolage-grotesque-latin-wght-normal.woff2` | Bricolage Grotesque (variable, 200-800) | SIL Open Font License 1.1 |
| `work-sans-latin-wght-normal.woff2` | Work Sans (variable, 100-900) | SIL Open Font License 1.1 |
| `b612-mono-latin-400-normal.woff2` | B612 Mono Regular | SIL Open Font License 1.1 |

The files come from the Fontsource packages (`@fontsource-variable/bricolage-grotesque`,
`@fontsource-variable/work-sans`, `@fontsource/b612-mono`). B612 was commissioned by
Airbus for cockpit displays, which is why it carries the dates and status labels here.
